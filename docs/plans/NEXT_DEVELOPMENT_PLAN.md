# 下一步计划：动态甲板姿态研究与安全高度验证

## 1. 目标

使用现有 `rollpitch` 和 `combined` 场景，完成动态甲板法向与角运动的理论复核、视觉可观测性评测和约 `5 m` 安全高度 shadow 验收。

本计划不开放相对下降、最终下降、真实接触、`NAV_LAND`、自动 Disarm 或 Ground Truth 控制。只有全部安全高度门槛通过并形成新的独立计划后，才能讨论下降能力。

## 2. 固定输入场景

### `rollpitch`

```text
roll amplitude:  5°，period 8 s
pitch amplitude: 3°，period 6 s
水平位移:       0
升沉:           0
```

### `combined`

```text
XY amplitude:    [1.0, 0.5] m
XY period:       [10.0, 6.0] s
heave amplitude: 0.30 m，period 8 s
roll amplitude:  5°，period 8 s
pitch amplitude: 3°，period 6 s
```

场景继续使用确定性 reset 和固定 seed。仿真 Ground Truth 只进入离线 evaluator。

## 3. 工作内容

### 3.1 理论与接口冻结

- 推导时变甲板平面、法向变化率、甲板角速度和局部接触点速度。
- 明确视觉法向时间序列可直接观测的量，以及必须估计或无法可靠估计的量。
- 量化图像采样、机体位姿插值、法向滤波和 Marker 切换引入的延迟。
- 比较直接差分、受限低通差分和小状态估计器；选择最小且可验证的方案。
- 将最终模型、单位、有效性、失效条件和 Ground Truth 隔离写入 `docs/reference/LANDING_CONTROL_THEORY.md`，再开始生产实现。

### 3.2 独立动态姿态估计

- 第一版实现为控制器节点内的独立普通 C++ 类，不新增 ROS 节点或自定义消息。
- 输入只允许视觉向上法向、视觉采样时间和已有 PX4/相机时间对齐结果。
- 输出至少包含滤波法向、法向变化率或等价角运动量、有效性、观测年龄和协方差/质量指标。
- 处理乱序、重复时间、长间隔、法向翻转、非法范数、Marker 切换和长时丢失。
- 初始阶段只发布 shadow 诊断，不接入着陆窗口、下降、触地检测或终端接触稳定化。

### 3.3 离线 evaluator

扩展语义化倾斜甲板 evaluator，按图像采样时间将视觉输出与 Ground Truth 对齐，统计：

- 完整法向角 RMSE、P95、最大误差和固定偏差。
- 法向变化率/角运动 RMSE、P95、符号正确率和相位延迟。
- Marker 切换前后法向与变化率跳变。
- 最大不可见间隔、有效样本覆盖率和时间同步失败数。
- 水平跟踪 RMSE、最大误差和相对速度。
- 状态机路径、恢复次数、非有限输出、`NAV_LAND` 和 Disarm 次数。

Ground Truth 只能在 evaluator 读取；增加静态检查，保证生产源码不存在 Ground Truth 订阅。

### 3.4 安全高度 shadow

- 默认保持现有安全高度和规则式水平控制。
- `rollpitch` 与 `combined` 强制关闭相对下降、最终下降和终端接触稳定化输出。
- 动态姿态估计只产生诊断，不修改 `TrajectorySetpoint`。
- 视觉失效仍沿用现有短时保持和 GNSS 恢复路径。
- 每个场景至少使用 3 个固定 seed，严格顺序运行，失败 seed 不重选、不调安全门覆盖。

## 4. 单元测试

至少覆盖：

- 常量法向输出零变化率。
- 已知正弦 roll/pitch 的方向、幅值和相位。
- 不同采样间隔与抖动。
- 重复、倒退和过大时间间隔。
- 法向半球翻转、非有限值和过小范数。
- Marker 切换跳变限制。
- 短时丢失保持与长时失效重置。
- 参数非法输入。
- shadow 输出不进入控制、窗口、下降和触地路径。

## 5. 安全高度验收门

以下门槛在真实 PX4 SITL Bag 上逐轮判断：

| 指标 | 门槛 |
| --- | --- |
| 水平误差 RMSE | `<= 0.08 m` |
| 水平最大误差 | `<= 0.15 m` |
| 完整法向角 RMSE | `<= 1.0°` |
| 完整法向角 P95 | `<= 1.5°` |
| Marker 切换法向跳变 | `<= 1.0°` |
| 动态估计有效覆盖率 | `>= 95%` |
| 时间同步失败 | `0` |
| NaN/Inf 输出 | `0` |
| `DESCEND` 及更低状态 | `0` |
| 接触/穿透 | `0 / 0` |
| `NAV_LAND / Disarm` | `0 / 0` |

法向变化率误差和相位延迟必须报告，但数值硬门需在理论复核和合成测试完成后、首次真实 SITL 前一次性冻结；不得根据真实 Bag 结果反向放宽。

## 6. 通过条件

只有同时满足以下条件，才能把本计划结论移入系统总览：

1. 理论、接口和阈值已在真实 SITL 前冻结。
2. 全工作区构建和测试通过。
3. `rollpitch` 3/3、`combined` 3/3 安全高度 shadow 通过。
4. 控制器 Ground Truth 订阅静态扫描为零。
5. 所有运行保持下降、接触、Land 和 Disarm 关闭。
6. 失败轮、命令、参数快照、Bag 和 evaluator 输出完整保留。

若任一硬门失败，本计划停在诊断和估计层，不调控制器扩大安全边界，也不创建动态姿态下降计划。

## 7. 明确不做

- 动态甲板姿态跟随或 PX4 attitude setpoint。
- 动态 `rollpitch`/`combined` 相对下降、最终下降和真实接触。
- 负倾角触地。
- 接触动力学 MPC、NMPC 或强化学习。
- Ground Truth 状态反馈。
- 自动 `NAV_LAND` 或 Disarm。
