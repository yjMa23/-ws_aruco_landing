# P6B 近距多尺度视觉验收计划

## 目标

验证远距 ID0 与近距 ID1~ID4 Marker 自动切换后，输出的始终为统一甲板中心位姿，并支撑后续最终下降。

## 执行顺序

1. 静止甲板 5 m 回归
   - 验证 ID0 主 Marker。
   - 检查水平跟踪不回归。

2. 静止甲板 0.50 m 安全高度
   - 不启用最终下降。
   - 验证 ID0 到近距 Marker 自动切换。
   - 检查切换前后甲板中心位置跳变。

3. P6B 最终下降复验
   - 显式启用最终下降。
   - 确认不因视场问题触发恢复。
   - 触地确认后保持，不发送 Land/Disarm。

## 验收指标

- active marker ID 可追踪。
- Marker 切换后 deck center 跳变 <= 0.05 m。
- 0.50 m 高度视觉持续有效。
- 不使用 Ground Truth 参与控制。
- 视觉失效仍进入安全恢复。

## 实验记录

### 5 m 远距回归

- ID0 为主 Marker。
- 水平位置 RMSE `0.0260 m`，最大水平误差 `0.0642 m`。
- Marker 丢失和 GNSS 恢复均为 `0`。
- 补偿后甲板中心 North/East 偏差约 `+0.0091/-0.0103 m`。

### 第一次 0.50 m 切换实验

Bag：`bags/p5b_static_descent_zff1p0_20260726_204030`。

- 状态链：`DESCEND -> RECOVER_CLIMB -> WAIT_LANDING_WINDOW`。
- 实际最低相对高度 `0.7443 m`，未到达 `0.50 m`。
- 下降阶段 `/aruco/id` 和 `/landing/active_marker_id` 均只有 ID0。
- ID1 只在 GNSS 会合阶段短暂出现两帧，近距未接管。
- 无 `NAV_LAND`、无 Disarm，视觉失效安全恢复逻辑有效。

结论：原配置 `ID0 priority=0 / ID1 priority=1` 会一直保留 ID0，直到其完全离开视场；切换重叠区不足。下一轮将两者设为同优先级并按图像面积选择，同时将 ID1 从 `0.16 m` 增至 `0.20 m`。

### 第二次启动回归

尝试将 ID1 PGM 从 `12x12` 提升到 `24x24` 后，控制器可正常起飞并进入 `ACQUIRE_ARUCO`，但整轮 `/aruco/pose` 与 `/aruco/id` 均为零。回退纹理后问题仍存在，进一步隔离发现根因是 ID1 扩大到 `0.20 m` 后与 ID0 平面边界接触，导致 Gazebo 中甲板 Marker 整体不可识别。

将 ID1 恢复为 `0.16 m`、保留同优先级面积选择后，`bags/p4_static_20260726_210319` 安全高度回归通过：状态进入 `WAIT_LANDING_WINDOW`，水平 RMSE `0.0259 m`，Marker 丢失和 GNSS 恢复均为 `0`。

随后 `bags/p5b_static_descent_zff1p0_20260726_210709` 再次在约 `0.71 m` 实际高度恢复，下降阶段仍只有 ID0，说明 `0.16 m` ID1 的检测重叠区不足。下一轮将 ID0 从 `x=0.35 m` 外移到 `x=0.45 m`，ID1 扩大到 `0.20 m`，两平面保留 `0.10 m` 间隙，同时继续采用同优先级面积选择。

新布局的 `bags/p4_static_20260726_211327` 远距回归通过：水平 RMSE `0.0308 m`，最大水平误差 `0.0601 m`，Marker 丢失和 GNSS 恢复均为 `0`；补偿后的甲板中心 North/East 偏差约 `+0.0096/-0.0056 m`。

将 ID1 纹理由 `12x12` 提升到 `36x36` 后，`bags/p5b_static_descent_zff1p0_20260726_212419` 低高度验收通过：

- 状态链正常进入 `DESCEND -> TEST_HEIGHT_HOLD`，没有恢复。
- ID0 在估计相对高度约 `0.928 m` 时切换到 ID1。
- 补偿后甲板中心三维跳变 `0.0277 m`，满足 `<= 0.05 m`。
- ID1 在后续下降与测试高度保持阶段持续可见。
- 估计/实际相对高度跟踪 RMSE 为 `0.0079/0.0207 m`。
- Ground Truth 最低相对高度 `0.4638 m`。
- 无 `NAV_LAND`、无 Disarm。

P6B.2 近距多尺度视觉切换验收通过，可以进入最终下降正向复验。

### 第一次多尺度最终下降复验

Bag：`bags/p6b_static_final_descent_zff1p0_20260726_212913`。

- ID0 到 ID1 的中距切换正常，ID1 在最终下降阶段持续工作到约 `0.258 m`。
- 最终下降参考/估计/Ground Truth 最低高度为 `0.2533/0.2584/0.2456 m`。
- 随后 ID1 再次超出超近距视场，状态按安全规则进入 `RECOVER_TO_GNSS`。
- 未形成触地候选或确认，无 `NAV_LAND`、无 Disarm。

结论：ID1 已解决中距视场问题，但不足以覆盖接触前最后约 `0.25 m`。下一轮增加中心 ID2 `0.08 m` 超近距 Marker，将 ID1 移至 `x=-0.18 m`，形成 ID0 `0.50 m`、ID1 `0.20 m`、ID2 `0.08 m` 三层尺度链。

三层布局的 `bags/p4_static_20260726_214137` 远距回归通过：水平 RMSE `0.0235 m`，最大水平误差 `0.0487 m`，Marker 丢失和 GNSS 恢复均为 `0`；补偿后的甲板中心 North/East 偏差约 `+0.0034/-0.0093 m`。

`bags/p6b_static_final_descent_zff1p0_20260726_214528` 中，ID1 在约 `0.46 m` 切换到 ID2，切换跳变约 `0.011 m`；ID2 工作到约 `0.24 m` 后开始间歇丢失，最终在参考/估计/Ground Truth 高度 `0.2271/0.2378/0.2245 m` 时触发视觉恢复。下一轮仅将中心 ID2 从 `0.08 m` 缩小到 `0.04 m`，以覆盖触地阈值 `0.18 m` 附近，不修改控制器、视觉超时或触地判据。

`bags/p6b_static_final_descent_zff1p0_20260726_215241` 中，`0.04 m` ID2 在约 `0.45 m` 接管，切换跳变约 `0.010 m`，但仍在估计高度约 `0.241 m` 开始长时丢失；参考/估计/Ground Truth 最低高度为 `0.2300/0.2377/0.1967 m`，未形成触地候选。下一轮将 ID2 侧移至 `x=+0.05 m`，新增中心 ID3 `0.02 m`，形成四层尺度链，以覆盖触地判据 `0.18 m` 附近的最后视场，不修改控制器、视觉超时或触地阈值。

`bags/p6b_static_final_descent_zff1p0_20260726_220148` 中，四层布局仍由 ID2 持续输出，ID3 只在远距偶发一帧；最终长时丢失时估计高度约 `0.240 m`、水平误差约 `0.018 m`，说明失效不是无人机偏离中心，而是同优先级最大面积规则阻止 ID3 提前接管。下一轮仅将优先级改为 `[ID0, ID1, ID2, ID3] = [3, 2, 1, 0]`，近距 Marker 被检测到后优先接管，并先做 `5 m` 回归。

近距优先配置的 `bags/p4_static_20260726_220931` 远距回归通过：系统稳定选择 ID1，水平 RMSE `0.0336 m`，最大水平误差 `0.0603 m`，Marker 丢失和 GNSS 恢复均为 `0`，没有 Marker 切换跳变。
